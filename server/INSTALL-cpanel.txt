تراپو — نصب در هاست cPanel با File Manager (بدون Git)
====================================================

این بسته دو پوشه دارد:
  public_html/  ← صفحه‌های سایت (تنها بخشی که از اینترنت دیده می‌شود)
  trapo_app/    ← کد سرور، کد رمزنگاری‌شده دوره‌ها، پایگاه داده و تنظیمات (بیرون از وب، کسی نمی‌بیند)

۱. بارگذاری
   - File Manager را باز کنید و به «پوشه خانه» بروید (پوشه‌ای که public_html داخلش است، مثل /home/USERNAME).
     مهم: فایل را داخل public_html بارگذاری نکنید.
   - trapo-cpanel.zip را همان‌جا Upload کنید، روی آن راست‌کلیک کنید و Extract را بزنید (مسیر همان پوشه خانه).
   - بعد از استخراج، فایل zip را پاک کنید.
   - برای دیدن فایل .htaccess: Settings (بالا سمت راست) ← Show Hidden Files (dotfiles).

۲. تنظیمات (فقط بار اول)
   - در trapo_app، فایل config.sample.php را Copy کنید با نام config.php (در همان پوشه trapo_app).
   - config.php را Edit کنید:
       base_url               نشانی سایت، مثل https://trapo.ir
       app_secret             ۶۴ نویسه تصادفی (0-9 و a-f)
       manage_password_hash   هش رمز پنل مدیریت سرور
     اگر cPanel شما «Terminal» دارد، این دو دستور مقدارها را می‌سازند:
       php -r "echo bin2hex(random_bytes(32)), PHP_EOL;"
       php -r "echo password_hash('یک-رمز-خیلی-قوی', PASSWORD_DEFAULT), PHP_EOL;"
     اگر Terminal ندارید، از پشتیبانی تراپو (سازنده برنامه) بخواهید config.php آماده را برایتان بسازد.
   - Permissions پوشه trapo_app/data را 750 و config.php را 640 بگذارید.

۳. هاست
   - MultiPHP Manager: نسخه PHP 8.0 یا بالاتر.
   - SSL/TLS Status: گواهی HTTPS برای دامنه (بدون HTTPS ورود کار نمی‌کند).
   - سایت را باز کنید: باید صفحه ورود / ثبت‌نام بیاید. پنل مدیریت سرور: https://دامنه/manage/

۴. به‌روزرسانی (نسخه تازه)
   - همین zip تازه را دوباره در «پوشه خانه» Extract کنید و «Overwrite» را تأیید کنید.
     config.php و پایگاه داده (کاربران، سفارش‌ها، پیشرفت) در بسته نیستند و دست نمی‌خورند.
   - اگر سایت را با Git™ Version Control نصب کرده‌اید، به‌روزرسانی می‌تواند خودکار باشد: در Cron Jobs یک کار
     «Once Per Fifteen Minutes» با این فرمان بسازید (مسیر = Repository Path صفحه Manage):
       /bin/bash /home/USERNAME/repositories/Trapo/tools/cpanel-autodeploy.sh >/dev/null 2>&1
     گزارش هر انتشار در فایل trapo-autodeploy.log در پوشه خانه نوشته می‌شود.

۵. فروش دوره (هر دوره یک بار خرید، دسترسی دائمی)
   - کاربر در برنامه «خرید دوره» را می‌زند، دوره‌ها را انتخاب می‌کند و سفارش ثبت می‌شود؛ پیام آماده سفارش را
     با دکمه تلگرام، بله یا ایمیل برایتان می‌فرستد (نشانی‌ها در بخش 'contact' فایل config.php).
   - بعد از دریافت پول، در پنل مدیریت سرور (https://دامنه/manage/) روی همان سفارش «پرداخت شد» را بزنید؛
     دوره‌ها خودکار و برای همیشه روی حساب کاربر باز می‌شوند و کد فعال‌سازی لازم نیست.
   - در «کاربران» با دکمه هر دوره می‌توانید دوره‌ای را دستی باز کنید یا دسترسی را بردارید.
   - کد تخفیف را در «کد تخفیف» پنل بسازید (درصد، مهلت، سقف استفاده، دوره‌ها).
   - قیمت‌ها در بخش 'prices' و نماد اینماد در بخش 'enamad' فایل config.php است (نمونه در config.sample.php).

۶. پرداخت آنلاین با زیبال
   - کد مرچنت درگاه Therapo داخل برنامه است و پرداخت آنلاین خودکار روشن است. برای تغییر، در trapo_app/config.php:
       'zibal' => ['merchant' => 'کد-مرچنت-دیگر'],   یا 'off' برای خاموش کردن، یا 'zibal' برای امتحان بدون پول واقعی.
   - base_url در config.php باید دقیقاً دامنه‌ای باشد که درگاه زیبال برایش ثبت شده (مثل https://therapo1.ir).
   - با روشن شدن، در پنجره خرید دکمه «پرداخت آنلاین و باز شدن فوری» می‌آید؛ بعد از پرداخت موفق، دوره‌ها خودکار
     و برای همیشه روی حساب خریدار باز می‌شوند. خرید با پیام به پشتیبانی هم کنارش می‌ماند.
   - اگر خریداری پرداخت کرد ولی به سایت برنگشت، در پنل مدیریت ← سفارش‌ها دکمه «بررسی پرداخت در زیبال» را بزنید.
   - به‌روزرسانی به این نسخه هیچ حساب، رمز، پیشرفت یا سفارشی را پاک نمی‌کند؛ فقط یک جدول تازه (purchases) اضافه می‌شود.

هرگز این‌ها را در هاست نگذارید: فایل trapo-admin-key.txt، پوشه‌های src، admin و tools.
