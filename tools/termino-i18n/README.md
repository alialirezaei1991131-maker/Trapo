# ترجمه انگلیسی حیطه‌های ترمینو

- `en/*.txt`: فرهنگ ترجمه؛ هر خط `شناسه<TAB>ترجمه`. شناسه = ۸ نویسه اول SHA-1 متن فارسی (رشته یا قالب با جای‌نگهدار ⟦i⟧).
  `شناسه@حیطه#n` ترجمه ویژه رخداد n‌ام در یک حیطه است (مثلاً معنی کوتاه واژه‌نامه).
- `tu.py`: استخراج واحدها از کد حیطه (`todo`)، بررسی تکه ترجمه (`check`)، آمار (`stats`) و ساخت نسخه انگلیسی (`build_en`).
- ساخت: نسخه انگلیسی هر حیطه (`courses/termino/<حیطه>.en.js`) فقط وقتی ساخته می‌شود که همه رشته‌هایش ترجمه شده باشند.
- آزمون‌ها: `enscan.js` (حرف فارسی باقی‌مانده)، `glosscheck.js` (معنی‌ای که خود واژه را لو می‌دهد)، `dupcheck.js` (گزینه تکراری).
